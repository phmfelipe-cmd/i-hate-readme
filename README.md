## 📌 Overview
This repository contains a tool that helps developers create README files automatically using an AI. The tool solves the pain of writing READMEs manually by utilizing a Groq API to fetch information about the project and generate a README based on that information.

## ✨ Features
- File-tree scanning to gather project details
- Zero-config API key persistence for Groq API
- Dynamic model fallback to handle different project structures

## 🛠️️ Tech Stack
- Groq SDK for interacting with the Groq API
- Node.js for executing the cli application

## 🚀 Quick Start
To install and run the i-hate-readme cli application, follow these steps:
```bash
npm install -g i-hate-readme
```

To reset the API key:
```bash
i-hate-readme --reset-key
```
